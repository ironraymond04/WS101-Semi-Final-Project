# Domain docs

This is a single-context repository. When relevant domain documentation exists, consult:

- `GLOSSARY.md` for established project terminology.
- `docs/adr/` for decisions related to the area being changed.

If these files are absent, continue without treating their absence as a setup issue. Use glossary terms in output; if a needed term is missing, flag the gap. Surface conflicts with relevant ADRs rather than silently overriding them.
